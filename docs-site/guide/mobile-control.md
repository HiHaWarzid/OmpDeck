# 手机控制

OmpDeck 可以在手机浏览器里查看历史会话、打开历史会话、新建会话并继续对话。它复用桌面端同一套 Renderer 和 Web 服务，不需要安装 App，也不依赖第三方中转服务。

## 能做什么

- 按项目查看历史会话列表，打开并恢复历史会话。
- 新建会话、发送消息、停止正在运行的 Agent。
- 切换模型和思考级别。
- 回答 Agent 的确认/选择请求，处理项目信任确认。
- 长会话按需加载更早的消息。

手机端聚焦“聊天与会话控制”。终端、文件树/编辑器、Git 面板、配置/Skills/Extensions、会话导入/导出/重命名/删除、项目管理等桌面专属能力仍请在桌面端操作。

## 开启步骤

1. 在桌面端打开 **设置 → Web 服务**。
2. 打开服务开关。
3. 选择监听地址：
   - **仅本机（127.0.0.1）**：默认值，只有这台电脑能访问。
   - **局域网（0.0.0.0）**：允许同一局域网内的手机访问。需要显式切换。
4. 确认端口（默认 `8765`），必要时在系统防火墙放行。
5. 手机与电脑连同一个局域网，扫描设置页二维码，或复制带令牌的地址在手机浏览器打开。

首次打开后，令牌会保存在该浏览器的本地存储中，地址栏里的 `?token=` 会被移除，后续可直接访问站点地址。

## 访问令牌

- 非回环请求（手机、其他电脑、隧道域名）必须携带令牌；只有 `127.0.0.1`、`localhost`、`::1` 等本机 Host 免令牌。
- 令牌由主进程自动生成，默认有效期 **30 天**，可在设置页改为 1 天、7 天、30 天或永不过期。
- **轮换令牌**会让所有已保存旧令牌的手机立即掉线，需要重新扫码。
- 手机丢失或令牌泄露时：先在桌面端轮换令牌，必要时关闭 Web 服务。
- 不要把带令牌的二维码、链接或截图发到公开渠道。

## 安全建议

- 默认只监听 `127.0.0.1`。只有确实需要手机访问时才切到 `0.0.0.0`。
- 局域网裸 HTTP 不加密，令牌和会话内容会以明文经过 Wi-Fi。可信家庭/办公网络可用；公共 Wi-Fi 不建议直接暴露。
- 需要跨网络或 HTTPS 时，推荐 **Tailscale Serve** 或 **Cloudflare Tunnel** 等私有组网/隧道方案，把服务入口收敛到 HTTPS，再配合令牌访问。
- 不要把 `8765` 端口直接映射到公网。
- Web 服务只做单令牌鉴权，没有多用户、角色或按设备撤销能力；它是个人开发机的远程入口，不是多人共享服务。

## 安装为 PWA

在 HTTPS 或 `localhost` 等安全上下文中，可以把 OmpDeck 添加到手机主屏幕：

- **iOS Safari**：分享 → 添加到主屏幕。
- **Android Chrome**：菜单 → 安装应用/添加到主屏幕。

Service Worker 预缓存应用外壳，导航请求网络优先，哈希静态资源缓存优先；`/api/` 会话数据不会写入缓存。局域网裸 HTTP 通常不满足 PWA 安装条件，这是浏览器限制，不是应用开关问题。

## 常见问题

**手机打不开页面**

- 确认电脑和手机在同一局域网，且没有开启访客网络隔离。
- 确认监听地址是 `0.0.0.0`，并使用电脑的局域网 IP，而不是 `127.0.0.1`。
- 检查系统防火墙是否放行端口。

**提示缺少令牌 / 令牌无效 / 令牌已过期**

- 重新扫描设置页最新二维码，或复制最新地址。
- 令牌过期或被轮换后，旧链接立即失效。
- 清除了浏览器站点数据也会丢失本地令牌。

**二维码显示 localhost**

监听地址还是“仅本机”。切换到“局域网”后，设置页会使用可路由的局域网地址生成二维码。

**PWA 无法安装**

确认通过 HTTPS 访问，或在本机 `localhost` 访问。纯局域网 HTTP 下页面仍可使用，但浏览器不会注册 Service Worker。
